# Productivity Tracker (Python)

A Python-based productivity tracking and analytics tool that logs daily activities,
analyzes time usage using NumPy, and visualizes results with Matplotlib.

## Features
- Log daily activities and duration
- Statistical analysis (mean, max, std)
- Visual summaries of productivity

## Technologies
- Python
- NumPy
- Matplotlib

## How to Run
```bash
pip install -r requirements.txt
python main.py
